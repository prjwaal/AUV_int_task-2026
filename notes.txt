src/
	auv_interfaces 
		msg/VehicleState.msg:  Published on /auv/telemetry (20 Hz)
			position, orientation, depth, linear_velocity, angular_velocity, battery_voltage, battery_percentage, and status
		msg/SystemStatus.msg:  Published on /auv/status (2 Hz)
			operational state (DISARMED, ARMED, MISSION_ACTIVE, ABORTING, FAULT) and status text
		msg/Heartbeat.msg:     Published on /auv/heartbeat (1 Hz)
			A lightweight timestamped ping used by the ground station to verify the link is alive.
		srv/SetArmed.srv:       Used by /auv/arm
			Request: bool arm $\rightarrow$ Response: bool success, string message
		srv/MissionCommand.srv:    Used by /auv/mission_command
			Sends START, STOP, or ABORT commands and returns bool success, string message
		action/SetTargetDepth.action:      Used by /auv/set_target_depth
			Defines Goal (target_depth, tolerance), Feedback (current_depth, depth_error), and Result (success, final_depth, message)
